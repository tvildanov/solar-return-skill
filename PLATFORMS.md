# ChatGPT, Claude, Grok, Gemini и другие агенты

Документация платформ сверена **13 ноября 2026** по официальным источникам ниже. Интерфейсы, тарифы и ограничения организации меняются. Это инструкции подключения, **не заявление об успешной установке в каждом аккаунте**.

Одна ссылка для распространения: **https://github.com/tvildanov/solar-return-skill**. [Начать без технической подготовки](START.md).

**[Набор для передачи человеку](https://github.com/tvildanov/solar-return-skill/raw/main/solar-return-assistant-kit.zip)** содержит пять самостоятельных текстовых инструкций, `README-FIRST.md` и внутренний `solar-return.zip`. Сначала распакуйте набор и выберите файл для своего агента. Весь kit не является автоматически устанавливаемым plugin или Skill.

## Три разных действия

1. **Прочитать:** вставить запрос, открыть GitHub или приложить Markdown. Ассистент получает инструкции/данные для разговора.
2. **Подключить:** сохранить инструкции в Project/Skills либо установить навык/плагин средствами конкретного клиента. Нужны доступные функции и разрешения.
3. **Вычислить:** действительно запустить калькулятор со всеми зависимостями либо получить результат из браузера. Ни ссылка, ни ZIP, ни пункт в списке Skills сами по себе этого не доказывают.

| Где вы работаете | Начать разговор | Повторное использование | Где получаются числа |
|---|---|---|---|
| ChatGPT | [Скопировать инструкцию](adapters/chatgpt.md) | Личный Project; Skills/Plugins там, где доступны | Проверенный запуск в доступной среде или браузер |
| Claude | [Скопировать инструкцию](adapters/claude.md) | `solar-return.zip` через Customize → Skills | Code execution с нужными пакетами или браузер |
| Grok web / mobile | [Скопировать инструкцию](adapters/grok.md) | Необязательно сохранить инструкцию как Skill | Проверенный запуск при наличии инструментов или браузер |
| Gemini | [Скопировать инструкцию](adapters/gemini.md) | Skills или Gems, если доступны | Проверенный запуск при наличии инструментов или браузер |
| Codex / Cursor / Claude Code / Grok Build | Каноническая папка `solar-return/` | Локальная установка ниже | Python 3.9+ и зависимости |
| Другой чат без Python | [Общая инструкция](adapters/any-agent.md) | Зависит от чата | Браузерный калькулятор → текст в чат |

Все разговорные prompts содержат уточнение данных, исправления и добровольное исследование времени рождения. Они не являются отдельными астрономическими алгоритмами. [Состав adapters/](adapters/README.md).

## Общий путь без среды выполнения

Откройте **[браузерный калькулятор](https://tvildanov.github.io/solar-return-skill/)**, заполните поля, нажмите «Рассчитать» → «Скопировать запрос для любого ИИ» и вставьте результат в свой чат. Альтернатива — «Скачать отчёт (.md)». Новый аккаунт в этом проекте, API-ключ и установка пакетов не нужны.

Ассистент должен назвать результат **предоставленным расчётом**, если сам не запускал вычислитель. Изменение исходных данных требует повторного расчёта. При неизвестном времени сначала выберите явно условный сценарий или отложите точную карту. Не скрывайте неопределённость за секундной точностью вывода.

Python-скрипт `rectify.py` исследует временной интервал и при желании ранжирует кандидатов по датированным событиям. **Браузерная форма не запускает эту ректификацию.** Без Python в чате можно обсудить записи, подготовить данные и сравнить отдельные браузерные сценарии, не обещая восстановить фактическое время.

<a id="chatgpt"></a>
## ChatGPT

### Разговор и Project

Скопируйте [adapters/chatgpt.md](adapters/chatgpt.md) в сообщение. Если ссылка не открывается, используйте сам текст. Для нескольких разговоров можно создать личный Project: **New project**, затем **Project settings** и добавить текст адаптера в инструкции. Отчёты можно добавлять как файлы/текст. Project хранит контекст, но не устанавливает Python-пакеты. Не используйте общий Project для личных данных рождения. [OpenAI: Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt).

Доступный инструмент анализа данных иногда выполняет Python, но это не гарантия наличия `pyswisseph` или разрешённой установки. Попросите проверить импорт, файлы и реальный запуск. При блокере переходите к браузеру. [OpenAI: data analysis](https://help.openai.com/en/articles/8437071).

### Устанавливаемый навык / plugin

В поддерживаемом ChatGPT интерфейсе навык можно выбрать через `@`; в Codex CLI/IDE — через `/skills` или `$solar-return`. Для локального Codex используйте установщик ниже. Для workspace используйте plugin-каталог, а не предположение, что отправленный ZIP автоматически появился в Skills. [OpenAI: Build skills](https://learn.chatgpt.com/docs/build-skills).

Создание custom GPT **не является обязательным шагом**. Доступность создания/редактирования и переход к Plugins зависят от аккаунта; следуйте актуальному уведомлению своего workspace. Если у вас уже есть доступный редактор GPT, текст адаптера относится к Instructions, а отчёты — к справочным файлам. Это не устанавливает зависимости и не создаёт расчётный API. [OpenAI: GPT availability](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts).

<a id="claude"></a>
## Claude

**Без установки:** вставьте [adapters/claude.md](adapters/claude.md), затем используйте предоставленный отчёт или доступную вычислительную среду.

**Как постоянный навык:**

1. Просмотрите исходники и скачайте [solar-return.zip](https://github.com/tvildanov/solar-return-skill/raw/main/solar-return.zip), сверив [SHA-256](solar-return.zip.sha256).
2. Откройте **[Customize → Skills](https://claude.ai/customize/skills)** → **+ → Create skill → Upload a skill** и загрузите ZIP целиком. Не подменяйте его plugin ZIP.
3. Включите навык и **Code execution and file creation** / **Create and edit files**, если доступно. В организации это может требовать разрешения администратора.
4. Напишите: «Используй solar-return, сначала уточни мои данные и точность времени рождения; объясни, можешь ли выполнить расчёт».

Загрузка в сообщение и загрузка через Skills — разные действия. Если меню отсутствует или установка зависимости запрещена, используйте разговорный адаптер и браузер, не обходите ограничения. [Claude: использование Skills](https://support.claude.com/en/articles/12512180-use-skills-in-claude), [формат custom skills](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills).

Claude Code использует папку навыка и свою среду выполнения: см. локальную установку ниже. Загрузка в один клиент не доказывает наличия файлов в другом.

<a id="grok"></a>
## Grok

**Основной путь:** вставьте весь [adapters/grok.md](adapters/grok.md) в Grok. При необходимости приложите Markdown-отчёт через **+** у поля сообщения или вставьте текст результата. Поддержка файлов документирована для web/iOS/Android; успех загрузки нужно проверить в самом чате. [Grok: Files & Data](https://docs.x.ai/grok/faq#files-data).

**Необязательно:** если доступен Skill Creator, попросите: «Сохрани эту инструкцию как навык Solar Return, без моих личных данных рождения и событий». Проверьте сохранение и вызов в новом разговоре. Официальное описание Grok Skills предусматривает создание через разговор или файл, но не доказывает совместимость данного skill ZIP или доступность `pyswisseph` в вашем аккаунте. [Grok: Skills](https://x.ai/news/grok-skills).

**Grok Build — отдельный вариант:** обнаруживает `.grok/skills/` в проекте и `~/.grok/skills/` в профиле; поддерживает `SKILL.md` с YAML-заголовком и команды вида `/solar-return`. Используйте `--host grok-build` ниже. Это не установка в обычный чат Grok. [Grok Build: Skills](https://docs.x.ai/build/features/skills-plugins-marketplaces).

Документация **API Code Execution** не доказывает, что те же инструменты или пакеты есть в обычном чате. Репозиторий не разворачивает API и не требует его ключа: без подходящего runtime используйте браузер. [xAI: API Code Execution](https://docs.x.ai/developers/tools/code-execution).

<a id="gemini"></a>
## Gemini

**Самый простой путь:** вставьте [adapters/gemini.md](adapters/gemini.md) в чат. Можно приложить один файл инструкции/Markdown-отчёт и попросить прочитать его; если формат не принимается, вставьте текст. Загрузка репозитория или файла даёт контекст, но не устанавливает зависимости. [Google: загрузка файлов](https://support.google.com/gemini/answer/14903178?hl=en).

**Для повторного использования:** в аккаунтах с новым интерфейсом откройте **Customize → Skills → Create → Create manually**, задайте имя `solar-return`, краткое описание и вставьте текст адаптера в Instructions. Либо попросите создать Skill из этого текста без личных данных. Проверьте сохранение и доступность. Документация также описывает загрузку папки с `SKILL.md`, но здесь не заявлена проверенная установка Python-пакета в Gemini: скрипты, требующие интернета, ограничены. Не обходите ограничения для установки зависимостей; используйте браузерный результат. [Google: Skills](https://support.google.com/gemini/answer/17094296?hl=en).

Если в вашем аккаунте ещё **Gems**, используйте **Gems → New Gem**, вставьте текст в инструкции и сохраните. Google сообщает о переходе личных аккаунтов с Gems на Skills с ноября 2026; ориентируйтесь на доступный интерфейс. Не добавляйте личные отчёты в общедоступный Gem/Skill. [Google: Gems](https://support.google.com/gemini/answer/15146780?hl=en).

Gems/Skills, Gemini Apps и инструменты Gemini API не взаимозаменяемы. Сохранённая инструкция не доказывает наличие `pyswisseph`, а весь assistant-kit ZIP не предназначен для загрузки как один Gemini Skill. Для нового расчёта без рабочего runtime используйте общую браузерную схему.

<a id="local-skill"></a>
## Локальный навык: Codex, Cursor, Claude Code, Grok Build

Скачайте/клонируйте репозиторий и просмотрите код. Из его корня проверьте план без записи:

```bash
python3 tools/install_skill.py --host codex --project /absolute/path/to/project --dry-run
```

После проверки и нужного разрешения повторите без `--dry-run`. Выберите `codex`, `cursor`, `claude-code` или `grok-build`. Для профиля текущего пользователя замените `--project ...` на `--user`.

| `--host` | В проекте | В профиле |
|---|---|---|
| `codex` | `.agents/skills/solar-return` | `~/.agents/skills/solar-return` |
| `cursor` | `.cursor/skills/solar-return` | `~/.cursor/skills/solar-return` |
| `claude-code` | `.claude/skills/solar-return` | `~/.claude/skills/solar-return` |
| `grok-build` | `.grok/skills/solar-return` | `~/.grok/skills/solar-return` |

Копировщик переносит **явно перечисленные файлы** из `tools/package_skill.py`. Он не скачивает зависимости, не запускает калькулятор, не меняет настройки, не перезаписывает существующий навык и отклоняет символьные ссылки в целевом пути. Обновление старой копии — отдельное решение.

Проверьте обнаружение навыка в клиенте; при необходимости перезапустите его. В Cursor / Claude Code / Grok Build используйте `/solar-return`. В удалённой среде нужны её собственные файлы и Python: установка на ноутбуке туда не переносится автоматически. [Codex](https://learn.chatgpt.com/docs/build-skills), [Cursor](https://cursor.com/docs/skills), [Claude Code](https://code.claude.com/docs/en/skills), [Grok Build](https://docs.x.ai/build/features/skills-plugins-marketplaces).

Python-среда создаётся **отдельно**, после нужного согласования:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r solar-return/requirements.txt
.venv/bin/python solar-return/scripts/solar_return.py --help
```

Это команды POSIX (Linux/macOS), не проверка каждой ОС. Укажите агенту абсолютный путь к готовому интерпретатору. В зависимости от версии Python и ОС пакет может потребовать сборки. Не используйте `sudo pip`, системный Python или обход запретов. Если пакет не устанавливается, опишите ошибку и используйте браузерный путь.

## Portable plugin и каталоги

`plugins/solar-return/plugin.json` следует формату **Agent Plugins 1.0**; `skills/solar-return/` — генерируемая копия канонической папки. Пакет не содержит MCP-сервера, hooks, автоматической установки зависимостей или удалённого API. [OpenAI: package format](https://developers.openai.com/plugins/build/plugins).

- **ChatGPT workspace:** администратор может открыть **Admin → Plugins → Add → Import marketplace**, указать URL репозитория в Source, оставить Path пустым и выбрать проверенный commit или ветку. Затем проверить Import results и настройки установки. Импорт не равен установке для пользователя или успешному запуску; синхронизация ветки может приносить обновления. [OpenAI: GitHub import](https://learn.chatgpt.com/docs/enterprise/plugin-management).
- **Cursor:** в поддерживаемом интерфейсе Customize используйте **From GitHub Repository** и URL репозитория; `.cursor-plugin/marketplace.json` указывает на plugin. После импорта проверьте установку и наличие навыка. Альтернатива — разрешённый локальный импорт `plugins/solar-return`. [Cursor: import](https://cursor.com/docs/skills).
- **Codex:** `.agents/plugins/marketplace.json` описывает локальный plugin. Добавление marketplace, установка plugin и запуск калькулятора — отдельные проверки. Следуйте текущему интерфейсу и ограничениям аккаунта. [OpenAI: plugins](https://developers.openai.com/plugins/build/plugins).

[Скачать plugin ZIP](https://github.com/tvildanov/solar-return-skill/raw/main/solar-return-plugin.zip) · [SHA-256](solar-return-plugin.zip.sha256) · [Состав plugin](plugins/solar-return/README.md).

Пакет подготовлен для этих путей импорта, но не заявлен как опубликованный в публичных каталогах. В каждом клиенте может понадобиться собственное действие пользователя/администратора. Не импортируйте исходники автоматически только потому, что ассистент прочитал ссылку.

## Проверка результата и приватность

Попросите ассистента указать: **(1)** что прочитано; **(2)** установлен ли навык и где; **(3)** какая среда и зависимости реально доступны; **(4)** какой запуск завершён или чей отчёт импортирован. Если версия/commit неизвестны, так и написать. Для повторяемости сохраняйте версию и проверенный commit: `main` меняется.

Проверьте входные данные, статус времени рождения, зоны, систему домов, дату возврата и 24 интервала. Рейтинг ректификации не является вероятностью, доказательством или документальным подтверждением минуты рождения. После исправления данных старый результат остаётся старым сценарием, а не подтверждённой картой.

Браузер загружает ресурсы; поиск города передаёт его название в Open-Meteo. Вычисления выполняются в браузере. Сам Python-калькулятор не делает сетевых запросов, но установка пакетов обращается к их источникам. AI-сервис получает всё, что вы отправляете ему, а экспорт может содержать дату/время рождения, координаты и события. Не включайте личные данные в общий Skill, plugin, Project, issue или публичный репозиторий; храните только то, что решили сохранить.

Проверка формата и локальных копирований не заменяет установку в настоящем клиенте. Успешный расчёт не доказывает астрологическую трактовку. Датированные результаты технических проверок: [VERIFICATION.md](VERIFICATION.md), границы астрономического сравнения: [ACCURACY.md](ACCURACY.md). Астрология — материал для размышления, не научно подтверждённый прогноз и не профессиональная рекомендация.
